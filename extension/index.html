How it works

  1. Draw a route in the editor (Pen or Sketch), insert a shape, or select a mask / shape path in After Effects and press Use selected mask / shape path.
  2. Switch between Top, Front and Side views to set each point's depth and elevation, or type them in the Route tab.
  3. Press Apply to After Effects. Routecam adds a camera, a route path and a controller to the composition.
  4. Set timing on the Motion tab and the aim, roll and lens on the Camera tab. With Live ticked, every change is applied straight away.
  5. Tick layers on the Layers tab and press Animate layers to bring them in as the camera approaches.

Drawing in the Composition panel

After Effects does not let panels like this one draw or pick up clicks inside the Composition panel, so routes are drawn in the editor above. Two things work natively instead:

  • Before: draw a mask or shape path with After Effects' own Pen tool and import it here.
  • After: the route is the motion path of the RC Route Path layer. Select that layer and reshape the path in the Composition panel, then press Reload here.
